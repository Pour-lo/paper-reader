# 论文助手

在手机上把论文重新排成适合阅读的一列，图片点一下就能放大。文件只留在你的手机里，不会传到网上。

## 怎么用

1. 用 Chrome 打开这个网页（需要通过 https 链接，或把本文件夹放到一个本地网页服务里）。
2. 点「打开论文」，选择 PDF 或 Word（.docx）文件。
3. 用「字号 / 行距 / 背景」调到自己看着舒服的大小；也可在设置里把翻页方式改成「左右翻页」，并选择滑动、仿真翻书或不要动画。
4. 点图片可放大到全屏，两指缩放；公式或表格乱了就点「看原页」。
5. 在 Chrome 菜单里选择「添加到主屏幕」或「安装应用」，以后就能从桌面打开。

本目录里的 `paper-reader.zip` 是可直接发布的网页文件包（不含任何论文原文）。

## 说明

- 解析和排版都在你的手机里完成。
- 图里的尺寸标注会尽量留在图中，题注只出现一次；有的图分成上下两页时会拼在一起。
- Word 里的公式会尽量按原样显示（希腊字母、上下标、分式、根号、求和积分和矩阵）。个别老公式若只留下一张预览图，会显示这张图。
- 部分 PDF 的公式、复杂表格或英文乱码，请用「看原页」对照。
- 老版 Word（.doc）需要先另存为 .docx。
- 从桌面打开若还是旧图标，删掉快捷方式后再「添加到主屏幕」或「安装应用」一次。出现「有新版本，点此更新」时点一下即可，不必反复刷新。
